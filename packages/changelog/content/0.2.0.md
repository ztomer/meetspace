## Dark mode

- **No more white flash on launch.** A pre-React inline script in `index.html` reads the persisted theme (mirrored to localStorage) plus `prefers-color-scheme`, applies the `.dark` class, and switches the main window to a theme-matched background before the first frame paints. Overlay windows (composer, floating bar) stay transparent.
- **Contrast sweep.** A whole bunch of surfaces had hardcoded `text-white` on `bg-primary` (white-on-white in dark mode) or `bg-[#faf8f5]` / `from-stone-50` washes baked in. Fixed across:
  - Start-listening / record buttons on the welcome page and calendar/chat/onboarding surfaces.
  - Stop-listening button after a session is live.
  - Export modal (the surface, the radios, the export button).
  - "Open note" search dialog reached from calendar events.
  - Transcript model download button under Settings → Intelligence.
  - Onboarding welcome video gradients (the white-wash that hid content).
  - Instruction-screen shell.

## Cleanup

- **Sign-in instructions gone.** Meetspace is local-only and the upstream auth subsystem has been a no-op stub since Phase 1 — the `/instruction?type=sign-in` screen was walking users through a flow that didn't exist. Removed it, narrowed `InstructionType` to `"billing" | "integration"`.
- **Devtool navigation pruned.** Dropped the **Onboarding Tab** and both **Instruction** buttons from the devtool Navigation card.
- **Cargo warnings.** `cargo check --workspace` is now clean: deleted dead `WHISPER_LISTEN_PATH` / `cors_layer`, removed duplicate match arms in the tray version menu (Hyprnote → Meetspace rename fallout), fixed unused imports/variables, and silenced upstream `async-openai` noise with a single top-level `#![allow(..)]` (with a comment to re-apply after `scripts/refresh-vendor.sh`).
