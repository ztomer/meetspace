## What's local-only

- **Transcription** — Parakeet (Soniqo on Apple Silicon), Whisper Large V3, or any of the Cactus Whisper-CPP variants. Models download on demand. Audio never leaves your machine.
- **Language models** — point at Osaurus (default `localhost:1337`), Ollama, LM Studio, or any OpenAI-compatible endpoint via the Custom provider.
- **Integrations** — Obsidian (write to your vault), Notion (your token), Linear (your key). All run client-side; no OAuth callbacks.

## New in this fork

- **Centralized dark / light theming** — toggle at Settings → App → Appearance. Follows your OS by default. Built on a CSS-variable token layer so colors are configurable in one place.
- **Backup your vault** — Settings → Data → Backup copies sessions, transcripts, and audio to any folder for sync via Dropbox / iCloud / git.
- **Auto-export to Obsidian** — optional toggle that writes each finished session to your vault as markdown with frontmatter.
- **Local speaker diarization (Pyannote)** — Settings → Intelligence → Speaker diarization. After each meeting, segments are tagged with Speaker 1 / Speaker 2 / … using on-device Pyannote + ECAPA embedding models. No model download — the ONNX is bundled in the binary.
- **LLM-driven speaker name resolution** — when local diarization is enabled and an LLM is configured, the meeting's participant roster is matched against the transcript, so anonymous "Speaker 2" labels become real names automatically.
- **Calendar OAuth (Google + Outlook) via localhost PKCE** — Settings → Integrations → Google / Outlook Calendar. You register your own desktop OAuth client (free, ~5 min once per provider) and sign in; tokens stay on this device.
- **Google + Outlook calendar sync** — once connected, calendars and events sync directly into the sidebar agenda every 5 minutes. Tokens auto-refresh on expiry.
- **Cross-provider event deduplication** — when the same meeting surfaces from multiple sources (e.g. Apple Calendar synced to your Google account *and* the Google integration connected directly), only one copy is shown. Settings → Integrations → "Calendar source precedence" lets you reorder which provider wins.

## What was removed

- All Supabase / Stripe / billing infrastructure.
- Cloud STT / LLM providers (the upstream cloud service).
- Account and trial UI.
- OAuth-only integrations (Slack, Discord, GitHub, Jira) — they require a callback server.

For the full phased rewrite see [`docs/FORK_PLAN.md`](../../../docs/FORK_PLAN.md).
