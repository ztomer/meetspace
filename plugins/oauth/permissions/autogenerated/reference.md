## Default Permission

Default permissions for the oauth plugin

#### This default permission set includes the following:

- `allow-start-pkce-flow`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`oauth:allow-start-pkce-flow`

</td>
<td>

Enables the start_pkce_flow command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`oauth:deny-start-pkce-flow`

</td>
<td>

Denies the start_pkce_flow command without any pre-configured scope.

</td>
</tr>
</table>
