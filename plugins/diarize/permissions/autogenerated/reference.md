## Default Permission

Default permissions for the diarize plugin

#### This default permission set includes the following:

- `allow-diarize-audio`

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>

</td>

</td>
</tr>

<tr>
<td>

`diarize:deny-diarize-audio`

</td>
