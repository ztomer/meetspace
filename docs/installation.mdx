## Current availability

The CLI is currently available as a source build from the Meetspace repository. It includes the `meetspace mcp` server in the same executable.

<Warning>
  Homebrew, standalone release binaries, and Windows package-manager distribution are forthcoming. Do not rely on those channels yet.
</Warning>

## Install from the desktop app

On macOS, open **Settings → Developers** and select **Install**. Meetspace installs the bundled command at `~/.local/bin/meetspace` without sending data anywhere.

If your shell cannot find `meetspace`, add `~/.local/bin` to `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Build from source

To build the CLI yourself instead:

```bash
git clone https://github.com/fastrepl/meetspace.git
cd meetspace
cargo install --locked --path apps/cli
meetspace --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `meetspace`.

## Connect to local data

By default, the CLI looks for `meetspace/app.db` in your operating system's application-data directory. It also recognizes legacy Meetspace locations.

Open the desktop app once before using the CLI. For a custom database location, pass a global option or environment variable:

```bash
meetspace --db-path /path/to/app.db --json meetings list
MEETSPACE_DB_PATH=/path/to/app.db meetspace --json meetings list
```

If you have an Meetspace data directory containing `app.db`, use:

```bash
meetspace --base /path/to/meetspace-data --json meetings list
```

The CLI opens the database in read-only query mode. It does not create a database or run migrations.
