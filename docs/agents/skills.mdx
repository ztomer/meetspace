---

The public Meetspace skill gives agents one transport-agnostic workflow:

1. Prefer connected Meetspace MCP tools.
2. Fall back to `meetspace --json` when MCP is unavailable.
3. Resolve meeting IDs from search results.
4. Fetch meeting detail before transcript text.
5. Keep transcript reads bounded and never access SQLite directly.

## Canonical sources

- Public skill: `https://docs.meetspace.so/skill.md`
- Repository package: [`skills/meetspace`](https://github.com/fastrepl/meetspace/tree/main/skills/meetspace)

The repository package includes concise references for setup, CLI commands, MCP tools, and errors.

## Install in an agent

Install from the public documentation with the open skills CLI:

```bash
npx skills add https://docs.meetspace.so
```

For a filesystem-based agent, copy the complete `skills/meetspace` directory into that agent's skills directory. Keep the directory name `meetspace` so relative reference links continue to work.

<Note>
  Agent skill locations and installer commands vary by client. Follow your agent's skill installation instructions rather than copying only `SKILL.md`.
</Note>

The contributor skills under `.agents/skills` are internal repository workflows. They are not part of the public Meetspace skill.
