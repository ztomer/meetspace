Meetspace is a local-first meeting notetaker. The desktop app records meetings and keeps notes, summaries, transcripts, participants, and action items on your computer.

The `meetspace` executable provides two read-only interfaces to that data:

- A CLI for people, scripts, and agents that can run shell commands.
- A local MCP server for agents that support the Model Context Protocol.

Both interfaces use the same application queries and never migrate or modify your database. CLI export can write a user-selected file, but it refuses to replace an existing file unless you pass `--force`.

## The short version

1. Open a calendar event or create a note.
2. Click **Join & record** or **Record**.
3. Take rough notes in **Memos** while Meetspace listens.
4. Stop listening, then review **Summary** and **Transcript**.

Your app data is stored locally. If you choose a hosted transcription or language-model provider, the content needed for that feature is sent to that provider.

<Note>
  The CLI and MCP server are read-only with respect to Meetspace data. Homebrew, desktop-bundled CLI, and Windows binary distribution are planned and are not yet published.
</Note>
